## Features

### 1. Loading Screen
- Elegant splash screen with app name **Eldorado**

### 2. Login
- Secure login with username & password
- Credentials are saved in your browser

### 3. Dashboard
After login you will see 3 options:

| Option   | Description              |
|----------|--------------------------|
| Notes    | Create Books & Notes     |
| Images   | Upload & view images     |
| Videos   | Upload & view videos     |

### 4. Notes System

```
Notes → New Book → Inside Book → New Note
```

- Create multiple **Books** (like notebooks)
- Inside each book create unlimited **Notes**
- All notes are auto-saved
- Insert custom **Tables** inside notes (rows & columns selectable)
- Tables render properly (not as code)

### 5. Settings
- Click the ⚙️ icon on top right
- Change your **Username** and **Password**
- Changes are saved immediately

### 6. Images & Videos
- Upload multiple images
- Upload small videos (recommended under 8MB)
- Delete anytime

---

## Important Notes

- All data is stored **only in your browser** (localStorage)
- If you clear browser data, notes/images/videos will be lost
- Best experience on Chrome or Edge
- Works offline after first open
